# Lionel: Jungle Fury — iPhone app

A native iPhone app that wraps the browser game. The whole game (page, 3D and physics libraries) is inside the app, so it runs with no internet connection.

## What an .ipa can and cannot do

An iPhone will not install an `.ipa` by itself. Apple only lets iOS install apps that are **signed** with an Apple ID, and that step cannot be done on GitHub without your Apple credentials. So there are two ways to get the game onto your home screen.

### 1. No computer, no Apple account: Add to Home Screen

1. Turn on GitHub Pages for this repository (Settings → Pages → Deploy from a branch → this branch, folder `/docs`).
2. On the iPhone, open `https://dookdog.github.io/everysingleday/` in **Safari**.
3. Tap **Share → Add to Home Screen**.

You get a "Lionel" icon that opens full-screen and works offline after the first launch.

### 2. The real .ipa (needs a computer and a free Apple ID)

Every push builds an unsigned `LionelJungleFury.ipa` on GitHub's Macs. Download it directly:

`https://github.com/dookdog/everysingleday/releases/download/ipa-latest/LionelJungleFury.ipa`

(The same file is also in each build's **Artifacts** on the Actions tab, wrapped in a zip.) Then sign and install it with one of:

- **Sideloadly** (Windows or Mac): drag the `.ipa` in, enter your Apple ID, connect the iPhone, press Start.
- **AltStore**: install AltStore on the phone, then open the `.ipa` with it.

After installing, on the iPhone: Settings → General → VPN & Device Management → trust your Apple ID. On iOS 16 and later also turn on Settings → Privacy & Security → Developer Mode.

With a free Apple ID the app works for 7 days and then needs re-signing. A paid Apple Developer account ($99/year) makes that one year and allows TestFlight.

### 3. One-tap install from the phone (needs a paid Apple Developer account)

The GitHub build signs the app by itself when the repository has your signing files. After that, opening `https://dookdog.github.io/everysingleday/install.html` on the iPhone and tapping **Install** puts the app on the home screen with no computer.

One-time setup:

1. In your Apple Developer account, register the iPhone (its UDID), create an **App ID**, an **Apple Distribution** certificate and an **Ad Hoc** provisioning profile that includes the iPhone.
2. Export the certificate with its private key as a `.p12` file (Keychain Access → export) and download the `.mobileprovision` profile.
3. Turn each file into text: `base64 -i cert.p12 | pbcopy` and `base64 -i profile.mobileprovision | pbcopy`.
4. On GitHub: **Settings → Secrets and variables → Actions → New repository secret**. Add:
   - `IOS_P12_BASE64` — the certificate text
   - `IOS_P12_PASSWORD` — the password you chose when exporting
   - `IOS_PROFILE_BASE64` — the profile text
5. Re-run the "Build iPhone app (.ipa)" workflow (Actions tab → Run workflow).

The app takes the bundle identifier from your profile. Keep these files private: put them only into GitHub's secrets form, never into the repository or a chat.

This signing step has not been exercised yet, because it needs your certificate.

## Automated simulator run

Every build also launches the app in an iPhone simulator on GitHub's Mac, starts a game, and saves two screenshots (`title.png`, `playing.png`) to the build's artifacts and to the `ipa-latest` release. The build fails if the game page reports an error or does not start.

## Build it yourself on a Mac

```
python3 tools/build_pages.py     # copies the game into ios/www
cd ios
brew install xcodegen
xcodegen generate
open LionelJungleFury.xcodeproj
```

In Xcode, select the target → Signing & Capabilities → pick your team, then run on your iPhone.

## Files

| File | Role |
|---|---|
| `project.yml` | XcodeGen description of the Xcode project |
| `App/AppDelegate.swift`, `App/GameViewController.swift` | Full-screen web view that loads the bundled game |
| `App/Assets.xcassets` | App icon |
| `www/` | The game, generated by `tools/build_pages.py` (do not edit by hand) |

## Testing status

The app is compiled and launched in an iPhone simulator on every GitHub build. It has not been run on a physical iPhone, and the signing step is untested.
