# Lionel: Jungle Fury — iPhone app

A native iPhone app that wraps the browser game. The whole game (page, 3D and physics libraries) is inside the app, so it runs with no internet connection.

## What an .ipa can and cannot do

An iPhone will not install an `.ipa` by itself. Apple only lets iOS install apps that are **signed** with an Apple ID, and that step cannot be done on GitHub without your Apple credentials. So there are two ways to get the game onto your home screen.

### 1. No computer, no Apple account: Add to Home Screen

1. Turn on GitHub Pages for this repository (Settings → Pages → Deploy from a branch → this branch, folder `/docs`).
2. On the iPhone, open `https://dookdog.github.io/everysingleday/` in **Safari**.
3. Tap **Share → Add to Home Screen**.

You get a "Lionel" icon that opens full-screen and works offline after the first launch.

### 2. The real .ipa (needs a computer and a free Apple ID)

Every push builds an unsigned `LionelJungleFury.ipa` on GitHub's Macs. To get it: open the repository's **Actions** tab, open the latest "Build iPhone app (.ipa)" run, and download the `LionelJungleFury-ipa` artifact (a zip containing the `.ipa`). Then sign and install it with one of:

- **Sideloadly** (Windows or Mac): drag the `.ipa` in, enter your Apple ID, connect the iPhone, press Start.
- **AltStore**: install AltStore on the phone, then open the `.ipa` with it.

After installing, on the iPhone: Settings → General → VPN & Device Management → trust your Apple ID. On iOS 16 and later also turn on Settings → Privacy & Security → Developer Mode.

With a free Apple ID the app works for 7 days and then needs re-signing. A paid Apple Developer account ($99/year) makes that one year and allows TestFlight.

## Build it yourself on a Mac

```
python3 tools/build_pages.py     # copies the game into ios/www
cd ios
brew install xcodegen
xcodegen generate
open LionelJungleFury.xcodeproj
```

In Xcode, select the target → Signing & Capabilities → pick your team, then run on your iPhone.

## Files

| File | Role |
|---|---|
| `project.yml` | XcodeGen description of the Xcode project |
| `App/AppDelegate.swift`, `App/GameViewController.swift` | Full-screen web view that loads the bundled game |
| `App/Assets.xcassets` | App icon |
| `www/` | The game, generated by `tools/build_pages.py` (do not edit by hand) |

## Testing status

The Swift code was written without a Mac. The GitHub build is the first real compile; check the Actions tab for its result. The app has not been run on a physical iPhone.
